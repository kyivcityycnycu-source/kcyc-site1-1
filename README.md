# KMMR - Офіційна веб-платформа Київської міської молодіжної ради (КММР)

Офіційний веб-сайт **Київської міської молодіжної ради (КММР)** — це інтерактивна платформа для залучення молоді до активного громадського життя Києва, розвитку громадянського суспільства та координації молодіжних ініціатив. 

Сайт надає можливість ознайомитися з діяльністю ради, її структурою (департаментами), активними проєктами, можливостями для молоді (вакансії, стажування, волонтерство), а також подати заявки на участь або підтримку ініціатив.

---

## 🌟 Основний функціонал

### 1. Публічна частина
*   **Головна сторінка**: Презентація діяльності ради, місії та ключових показників.
*   **Проєкти (Projects)**: Перегляд поточних та завершених проєктів ради, з детальною інформацією про кожен проєкт у зручному модальному вікні із збереженням адаптивних пропорцій 2:1 для зображень.
*   **Можливості (Opportunities)**: Секція з відкритими вакансіями, волонтерськими програмами та освітніми заходами.
*   **Департаменти**: Ознайомлення зі структурою КММР та діяльністю кожного підрозділу.
*   **Форми зворотного зв'язку / Заявки (Contacts & Applications)**: Інтерактивні форми для:
    *   Загальних запитів.
    *   Реєстрації кандидатів у департаменти.
    *   Подачі заявок на підтримку молодіжних ініціатив.
*   **Двомовність (UA / EN)**: Повна локалізація інтерфейсу для українських та англомовних користувачів.

### 2. Панель адміністратора (Admin Dashboard)
Повнофункціональна закрита панель управління для координаторів КММР:
*   **Управління заявками (Applications Management)**:
    *   Перегляд поданих заявок у реальному часі з детальною інформацією у модальному вікні.
    *   Підтримка довгих email-адрес та номерів телефонів без спотворення інтерфейсу (автоматичний перенос слів).
    *   Динамічне відображення обраного департаменту з автоматичною підстановкою назви з бази даних замість ID-ідентифікатора.
    *   Експорт бази заявок у формат **Excel (.xlsx)** одним кліком.
*   **Управління командою (Team Members)**:
    *   Додавання, редагування та видалення членів команди.
    *   Сортування порядку відображення методом перетягування (Drag-and-Drop) або стрілочками вгору/вниз.
    *   Оптимізація зображень та завантаження фото в хмару з попереднім стисненням у браузері.
*   **Управління департаментами (Departments Management)**:
    *   Створення та налаштування департаментів (назва UA/EN, опис, іконки).
    *   Редагування черговості відображення.
*   **Аналітика та статистика**: Наочні інтерактивні графіки та діаграми активності подачі заявок.

## 🛠️ Технологічний стек

Платформа побудована на сучасному та швидкому стеку технологій:
*   **Frontend**: 
    *   [React 18](https://react.dev/) — бібліотека для побудови інтерфейсу користувача.
    *   [Vite](https://vitejs.dev/) — надшвидкий інструмент збірки та розробки.
    *   [TypeScript](https://www.typescriptlang.org/) — типізований JavaScript для підвищеної стабільності коду.
    *   [Tailwind CSS](https://tailwindcss.com/) — утилітарний CSS-фреймворк для адаптивного та сучасного дизайну.
    *   [lucide-react](https://lucide.dev/) — набір красивих та сучасних іконок.
    *   [motion](https://motion.dev/) — плавні анімації та мікро-взаємодії.
    *   [react-router-dom](https://reactrouter.com/) — маршрутизація сторінок.
*   **Backend & Database**:
    *   [Firebase Firestore](https://firebase.google.com/docs/firestore) — NoSQL хмарна база даних для збереження заявок, команди, департаментів та налаштувань у реальному часі.
    *   [Firebase Storage](https://firebase.google.com/docs/storage) — надійне збереження завантажених фотографій команди та іконок департаментів.
*   **Додаткові бібліотеки**:
    *   `browser-image-compression` — для стиснення завантажуваних зображень користувачами перед відправкою, що економить місце в хмарі.
    *   `xlsx` — для генерації Excel-звітів на стороні клієнта.
    *   `react-helmet-async` — для SEO оптимізації та управління мета-тегами.

## 📂 Структура проєкту

```text
├── src/
│   ├── components/            # Багаторазові компоненти інтерфейсу (кнопки, картки, секції сайту)
│   │   ├── ui/                # Базові UI компоненти (модальні вікна, форми тощо)
│   │   ├── ProjectsSection.tsx # Секція з проєктами КММР
│   │   ├── ApplicationDetailsModal.tsx # Модалка детального перегляду заявки в адмінці
│   │   └── ...
│   ├── context/               # Контексти React (наприклад, контекст мови LanguageContext)
│   ├── pages/                 # Повноцінні сторінки додатку
│   │   ├── AdminDashboard.tsx # Багатофункціональна панель адміністратора
│   │   └── ...
│   ├── services/              # Сервіси інтеграції (налаштування Firestore, завантаження файлів)
│   ├── utils/                 # Допоміжні утиліти
│   ├── App.tsx                # Головний компонент додатку, конфігурація роутингу
│   ├── firebaseConfig.ts      # Ініціалізація та конфігурація зв'язку з Firebase
│   ├── index.tsx              # Точка входу в додаток
│   ├── types.ts               # Глобальні описи типів та інтерфейсів TypeScript
│   └── constants.tsx          # Статичні текстові дані, константи та мовні переклади
├── public/                    # Статичні ресурси (логотипи, шрифти тощо)
├── package.json               # Залежності проєкту та npm скрипти
├── tsconfig.json              # Конфігурація компілятора TypeScript
└── vite.config.ts             # Конфігурація Vite збірки
```

## 🚀 Встановлення та запуск локально

Щоб запустити цей проєкт на локальному комп'ютері:

### 1. Клонування репозиторію
```bash
git clone <url-репозиторію>
cd kmmr-site
```

### 2. Встановлення залежностей
```bash
npm install
```

### 3. Налаштування змінних оточення (Environment Variables)
Створіть файл `.env` (або заповніть існуючі змінні) у кореневій директорії проєкту та додайте ваші ключі від Firebase:
```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id
VITE_FIREBASE_MEASUREMENT_ID=your_measurement_id
```

### 4. Запуск сервера розробки
```bash
npm run dev
```
Після цього додаток буде доступний за адресою: `http://localhost:3000` (або іншому порті, вказаному у терміналі).

### 5. Збірка для продакшену
Для компіляції та створення оптимізованого білду виконайте:
```bash
npm run build
```
Згенеровані статичні файли будуть збережені в папці `dist/`.

## 🔒 Безпека та Адміністрування

*   Доступ до панелі адміністратора (`/admin`) захищено авторизацією через **Firebase Authentication**.
*   Усі конфіденційні дії (редагування бази, перегляд персональних даних заявників) потребують авторизованого доступу.
*   Правила безпеки Firestore (Firestore Security Rules) налаштовані таким чином, щоб закрити читання списку заявок для неавторизованих користувачів, дозволяючи лише публічний запис нових анкет.
